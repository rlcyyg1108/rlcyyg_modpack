
# 改动 29（BUG 修复）：开场未放完就切模块，环心图片闪一下

用户：点击网站后若在开场动画没走完时选择模块，中间那板块的图片（环心 `#hubImg`）会闪。

## 根因
闪来自 `endBoot()` 的兜底淡入。CSS 里：
```
body.boot-skipped #ringWrap { animation: bootFade .25s ease-out both; }  /* from opacity:0 */
```
`#ringWrap` 的入场是【最早】的一批（bootRing，delay .05s / dur 1s），用户点模块时它多半
已显形大半；`endBoot()` 摘掉 `boot` 后，这条 boot-skipped 规则把它的透明度重置回 0 再淡入
= 把已经看到的环+环心图「从全黑重播一遍」→ 闪。（`#decor`/`#labels` 同理，只是不如图显眼。）

## 修法：把环 / 刻度 / 标签的入场从 boot 解耦到 `.anim-in`
- CSS：`body.boot #ringWrap, body.anim-in #ringWrap { animation: bootRing ... }`，
  `#decor`/`#labels` 同样加 `body.anim-in`。两条选择器声明【完全一样】，所以 boot→anim-in
  切换时动画名/参数不变 ⇒ 浏览器【接着播】而不是重播（这是关键，靠的是「同名动画不会重启」）。
- CSS：把 `#ringWrap/#decor/#labels` 从 `body.boot-skipped ...` 的 bootFade 列表里【移除】，
  该列表只留「交互时多半还没显形」的 `.panel-left/.panel-right/.corner-deco`。
- JS 启动：`document.body.classList.add('boot','anim-in')`。
- JS `endBoot()`：摘 `boot` 时【故意保留 anim-in】，另起 `setTimeout(...,1700)` 等它们各自
  跑完（最长 labels 约 1.55s）再摘 —— 此时动画已停在终态，摘了不算变化，不会闪。
- JS 正常路径的 2400ms 定时器：同时摘掉 `anim-in` 与 `boot`。

## 校验
`node --check script.js` 通过；CSS 括号平衡 269/269；`boot-skipped #ringWrap` 引用清零；
`anim-in` 在 CSS 3 条规则 + JS（启动加、endBoot 与 2400ms 两处摘）一致。

# 改动 30：链接板块「环心连线」→ 莫比乌斯带

用户要在线轮卡片之间加会动的连线，参考莫比乌斯环。落地方案 = M1 扭带（主）+ M3 单边流动。

## 几何（关键，别再推错）
卡片圆心本来就落在椭圆上：`P(t) = (cx − rx·cos t, cy + ry·sin t)`（与 `arcAt` 同一套）。
沿这条椭圆铺带子，**不需要**再过卡片中心做样条：
- 法线 `N = 切线转 90° = (−ry·cos t, rx·sin t)` 归一化
- 半宽 `w(t) = MB_W · cos(t/2 + 相位)`
- 绕一圈 `t/2` 走 0→π ⇒ `cos` **恰好过一次零、正负互换** ⇒ 一处「半扭」：带子收窄到零宽
  （侧对镜头）、越过之后两条边左右互换。相位随时间增长 ⇒ 扭结沿环游走。
- 两条边 `A=P+N·w`、`B=P−N·w`。**A(2π) 恒等于 B(0)**（因 `cos(π+ph)=−cos(ph)`），
  所以「A 走完接 B」天然拼成一条闭环 = 莫比乌斯的**单条边**（长 ≈ 2L）。虚线沿它流动。

## 落地
- CSS（`#deckMobius` / `.mb-band` / `.mb-edge`(+`@keyframes mbFlow`) / `.mb-knot`）：
  svg `position:absolute; inset:0; z-index:100` —— 【低于卡片 2000+】，垫在卡下、只在缝里露。
  edge `stroke-dasharray:7 9`，`stroke-dashoffset` 走到 −160（=16×10，周期整数倍，首尾无缝）。
- JS：`buildDeck` 之后建 `mobius`（insertBefore 成 #deck 首子元素）。`updateMobius(dt)`：
  采样 96 点，算 A/B 两串点，拼 `bandD = A正 + B倒 + Z`、`edgeD = A正 + B正 + Z`，
  扭结圆点放在 `min|w|` 处。`animLoop` 每帧调用（非链接板块内部立刻 return 并藏 svg）。
- 参数：`MB_W=9`（总宽 18）、`MB_N=96`、`MB_SPEED=0.5`（≈6.3s 扭结走一圈）。
- reduced-motion：全局 `*{animation:none}` 关掉流动，JS 里 `phase` 也冻结 ⇒ 只剩静态扭带。

## 校验（数值定点，非套件）
带子闭环 |A0−B_N| = 0.0000；单边闭环 |A_N−B_0| = 0.0000；每条弧段 w 过零次数 = 1；
最大总宽 18px；CSS 括号 275/275；`node --check` 通过。

# 改动 32：卡片改为不透明

用户：把卡片改为不透明。→ 去掉卡片的毛玻璃，改成实心深色。
- `.dcard`：`--fill: rgba(24,24,28,.56)` → `rgb(24,24,28)`（实心）；
  删 base 的 `backdrop-filter: blur(7px) saturate(.85)`（+ `-webkit-`）。不透明后模糊无意义且白耗性能。

- 删 `.dcard.cur` 里两行 `backdrop-filter:none`（base 已无，冗余）。
- 删移动端 `@media (max-width:768px){ .dcard{ backtrack... } }` 整块（原为降档模糊）。
- 边框圈仍是 `::after` 的 `rgba(255,255,255,.16)`（卡面 `::before` 只留 `--bw` 宽的一圈），
  选中卡走 `::after` 的不透明灰白渐变。不透明卡面顺便把穿过的莫比乌斯带彻底挡住（只在缝里露）。
