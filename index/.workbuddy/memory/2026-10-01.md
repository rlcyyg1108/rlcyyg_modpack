用户拍板：卡片用毛玻璃；选中卡灰白渐变则文字转深色；余摆过冲区分触发源。
**测试仍处停止状态**（用户此前明令），本轮只做了 3 次定点冒烟（语法 / 切板块 / 选择器命中）。

## ① 板块入场：每个板块一条轨迹（body[data-enter="<id>"]）
统一 1.05s + `cubic-bezier(.16,1,.3,1)`（与链接轮转 pow=4 同族），只换运动原语：
- core → `entSpread` 由内向外扩散，四角面板用 `--ex/--ey` 朝环心偏 20px，左栏 pane 26px
- interests → `entWipeX` 横向逐列擦除 `clip-path: inset(0 100% 0 0)→inset(0)`，stagger 90ms
- projects → `entWipeY` 纵向自下刷出，pane 与 br 面板错开 130ms
- artists → `entDevelop` 显影 `blur(5px)→0` + scale(.985)，四角 stagger 110ms
- links → 轮盘仍走 JS `deckEnter()`；`#linkHead`/`#linkBadges` 延后 .25s
- **坑（已规避）**：`data-enter` **写上后永不摘除**。摘掉会让动画名从 entXxx 退回
  `fadeIn`，浏览器当成新动画从头播 → 整块闪一下（与 1150 行那条 boot 注释同源）。
  只改值、不删除；`startEntry()` 里 removeAttribute → `void offsetWidth` → setAttribute 强制重播。
- `startEntry()` 在 boot 未结束时先调 `endBoot()`，否则 boot 的 delay 规则与入场抢时序。
- 另加一层零成本差异：`KICK_TAU_BY = {projects:.32, links:.38, interests:.40, core:.45, artists:.50}`，
  同一记冲量、不同衰减常数 ⇒ 收尾「利落 / 沉」分得开。

## ② 卡片：非选中毛玻璃 / 选中灰白
- 双层结构保留（clip-path 会切掉 border，只能用两层八边形）。
- 非选中：`--fill: rgba(24,24,28,.56)` + `.dcard` 上 `backdrop-filter: blur(7px) saturate(.85)`；
  描边改成**纯色** `rgba(255,255,255,.16)`（原来那圈流动渐变整体撤掉）。
  半透明必须配毛玻璃：纯透明会把后面卡片的类别名透成能读的第二行字（更早一版的鬼影毛病）。
  移动端 blur 降到 4px（十几个毛玻璃层同动，半径是主要开销）。
- 选中：`.dcard.cur` `backdrop-filter:none` + `::after{display:none}`，
  `::before` 铺满整卡 `repeating-linear-gradient(100deg, …)` 周期 240px、
  `deckFillCur 16s ease-in-out infinite alternate`，文字转 `#17171b`（`.dc-count` → rgba(18,18,24,.62)）。
- 无缝位移通式：`dx = 周期 / sin(角度)`（45° 时的「周期×√2」就是它的特例）。100° → 243.7px。
- JS 侧：`el.style.setProperty('--fill', …)` 整行删除（选中卡的 ::after 已 display:none），
  只留 `el.style.color = isCur ? '#17171b' : 'rgba(255,255,255,.92)'`。

## ③ 切卡余摆（过冲）
`deck` 加 `back` 字段；animLoop 里 `back ? easeOutBack(c1=1.1, c3=2.1) : 1-(1-p)^pow`。
- `deckStep`（滚轮/方向键）→ back=true；`deckPick`（点击）→ 仅 `|d| <= 2` 才 true
  （过冲按距离比例算，跨 9 格时冲出去半格太难看）；
- `deckTo` / `deckEnter` / `endDrag` 吸附 → back=false（手刚离开就回弹显得打滑）。

## ④ 三处常驻微动（周期互质，不打同一个拍子）
- 背景亮带：`bg.bt` 累加、`BG_BREATH=26` 秒正弦改 `#bgField` 的 opacity（0.86↔1）。
- 装饰线游走光点：`.dline::after` 2px 亮点，`decoDotX/decoDotY` 8s 沿「屏幕边缘→圆心」往复；
  右线/下线用 `alternate-reverse`（它们的圆心端在盒子另一侧）。位移只能用百分比（线长由 JS 算）。
- 选中标签呼吸：`.s-label.sel` `labelBreath 4s` opacity .72↔1，只有选中的那个在动。

## ⑤ 展示区条目 stagger
`panelSwap` 从 `.pn-list` 挪到 `.pn-item`；`mkRow(it, i)` 写 `animationDelay = min(i,12)*10ms`
（封顶 12 条，否则 30+ 站的分类最后几条要等半秒）。条目每次换卡重建 ⇒ 动画自然重播，
`pnList.style.animation = none → 重排 → ''` 那套 hack 已删。

冒烟结果：内联脚本语法通过；五个板块 data-enter 正确切换、无 JS 错误；
选择器命中 core 2/2、interests 4 面板+12 列、projects 1/1、artists 4、links 2。

# 改动 18：选中卡「与其他卡同一个八边形」+ 变白那一下的快速擦除 + 入场改逆时针

**测试仍处于停止状态**（用户明令）。本轮只对「旋转方向」做了一次定点核对（非套件）。

## ① 选中卡必须是【同一个八边形】
- 根因：`.dcard.cur` 之前单独写了 `--cut: 11px`（其它卡 9px），选中后切角变大 ⇒ 和其它卡
  **不是同一个八边形**。已删掉这条，统一沿用 9px；选中前后是同一个形状，只是变大、变亮。
- 注意：不要再给当前卡单独设切角。想让它「看起来一致」应该按比例，而用户要的是【完全一样】。

## ② 灰卡 → 灰白渐变：.26s 擦除（两个方向都有动画）
结构从「当前卡的 ::after 直接 display:none」改成**两张卡面叠着、靠过渡互换**：
- `.dcard::before`（z-index −2）= 灰白渐变层，**所有卡片都铺着、默认 opacity:0**，
  只有 `.dcard.cur::before` 才 opacity:1；渐变与 16s 往复动画仍只写在 .cur 上。
  所有卡都铺一份（而不是只在 .cur 上写 background-image）是必要的：
  否则取消选中时 background-image 瞬间消失 ⇒ 白→灰是硬跳，只有灰→白有动画。
- `.dcard::after`（z-index −1）= 灰色卡面，**不再 display:none**，改成
  `.dcard.cur::after { opacity:0; transform: translate3d(52%,0,0) }` ⇒ 向右滑出并淡掉，
  把下面的渐变「擦」出来。::after 自带八边形 clip-path，滑出途中始终是八边形，不露直角。
- 起始帧无跳变：t=0 时 ::before 还是 0、::after 还是 1，外观与选中前完全一致
  （唯一差别是 backdrop-filter 关了，而渐变层不透明，看不出来）。
- 时序：::before 淡入 .13s（渐变先就位），::after 滑出 .26s / 淡出 .22s。
- 字色过渡从 .22s 收到 **.14s linear**：卡片一变亮白字必须立刻转深，否则中间有一瞬看不见。

## ③ 入场旋转改成【逆时针】
- 方向推导（务必记牢，别再反）：`buildArc` 用 `x = cx − rx·cos t`、`y = cy + ry·sin t`（y 向下），
  所以 t 增大 = 左→下→右→上 = **逆时针**；弧长 s 随 t 增大，`ring[]` 随 s 增大
  = 上顶点→左→下→右 = 逆时针；而卡片 k 落在第 `k − deck.pos` 个卡位上
  ⇒ **deck.pos 变小 = 逆时针**。
- `deckEnter()`：`deck.from = to + spin`（原来是 `to − spin`，即顺时针）。
- 实测（1920 宽、N=18）：from=5.04 → to=0（pos 递减），卡0 极角 346° → 90°，Δ=+104° ⇒ 逆时针 ✓。
  spin 仍是「约 100° 折成格数」，`Math.max(0.6, Math.min(9, N*0.28))`，1.05s / pow 4。
- 只改入场；滚轮、拖拽、点击的方向不动。

# 改动 20（BUG 修复）：选中卡变成直角矩形 —— 合成子层绕过了父级 clip-path

用户截图：选中的那张是**直角矩形**，而且看着没有灰白渐变（普通卡是八边形、有描边）。

## 根因（重要，别再踩）
渐变层的旧结构是：`::before` 比卡片宽 640px、用一个 **transform 动画**做流动。
transform 动画会让这一层被提升为**独立合成层**，而 **Chromium 对合成子层不套用父级的
`clip-path`**（只认 `overflow: hidden` 的矩形裁剪）。于是：
- 父级 `.dcard` 的八边形被绕过 → 显示成一个 118×68 的**直角矩形**（矩形边界正是
  `overflow: hidden` 的裁剪）；
- 这一层又是整块渐变色 ⇒ 卡片看着就是一块平的浅色，没有"描边"也没有明显的渐变带。
- 普通卡一直看不出问题：它们的 ::before 是 `opacity: 0`，根本没被绘制。

## 两条修法
1. **给渐变层自己再挂一份八边形 `clip-path`**（`inset: 0` + 与本体同样的 `--cut`）。
   即使它被提升为合成层、绕过父级裁剪，自身的 clip 仍然生效。
   ⚠️ 推论：**这一层不能再靠 transform 平移来做流动** —— transform 会把自带的 clip
   一起挪走，等于没裁。所以流动改成动 `background-position`（纯绘制属性，不提升合成层）。
2. **让 background-size 正好等于一个渐变周期、首尾同色**，于是任意偏移下平铺无缝：
   `linear-gradient(90deg, #c4c4cc 0%, #f5f5f8 25%, #dcdce3 50%, #f1f1f5 75%, #c4c4cc 100%)`
   + `background-size: 200px 100%`，关键帧 `background-position: 0 → -200px`。
   16s / ease-in-out / alternate 不变。
   （旧版是 240px 周期的 repeating-linear-gradient 铺在 758px 宽的层上，卡片只露出 118px
   的切片，某些相位下几乎看不出渐变 —— 这也是"没有渐变"的观感来源。现在周期 200px、
   卡片能露出约 59% 的一个周期，灰白变化一眼可见。）

## 顺带
- `.dcard.cur::after` 的 `transform: translate3d(52%,0,0)` **撤掉**，改成纯 `opacity` 过渡
  （.26s）。理由同上：它自带的 clip 是固定的，加位移会让 clip 跟着挪，滑动途中露出直角。
  现在"灰 → 灰白"是 ::before 淡入 .16s + ::after 淡出 .26s 的交叉过渡，很短暂。
- 现在**卡片子树里一个 transform 都没有**（只有 `.dcard` 自己那份由 JS 每帧写的位置），
  两层伪元素各自带八边形 clip ⇒ 形状双保险。

# 改动 21：八边形四角痕迹的真正根因（本体矩形背景漏出）+ projects 左右方向对调

用户截图："四角还是有一点微微的痕迹，这个八边形并不完美"。

## 根因（实测，非猜测）
把截图 PNG 解码后逐像素采样（截图 237×135，卡片 bbox 恰为 118×69 ⇒ DPR=1，是桌面端真实像素）：

- 四角切角那块三角区颜色 = **#44444b**；背景 = #1f1f26。
  `rgba(255,255,255,.16)` 叠在 #1f1f26 上 = (0.16×255+0.84×31)=**#43434a** ⇒ 差 1，完全吻合。
- 该三角区的**外边是直角**（卡片矩形的上/左边界），内边才是八边形的斜边。

结论：**`.dcard` 本体那条 `background: rgba(255,255,255,.16)` 是按「矩形」画出来的**，
它的 `clip-path` 没吃到自己的 background。原因是本体是合成层（`will-change:transform`
+ 每帧 JS 写 transform）。矩形底被上面的八边形卡面盖住中间，只在四角漏出四块直角；
普通卡漏出来的颜色和描边同色看不出来，选中卡一铺灰白渐变就成了四个刺眼的缺口。
（伪元素自己身上的 clip 是生效的 —— 卡面那条斜边就是它裁出来的。）

## 修法：本体一像素都不画，两个伪元素互换角色
- `.dcard` → `background: none`（clip-path 留着，只用于裁 backdrop 模糊范围）。
- `.dcard::after`（z-2，下层，`inset: 0`，`--cut`）= **描边/底色层**：
  非选中 `rgba(255,255,255,.16)`；选中整块铺灰白渐变 + `deckFillCur`。
- `.dcard::before`（z-1，上层，`inset: var(--bw)`，`--cut2`）= **卡面**：
  非选中 `var(--fill)` 毛玻璃底；选中 `opacity: 0` 淡出让出渐变。
- 静态观感与改动 20 完全一致（非选中 1.3px 描边、选中渐变铺满整块），
  只是四角那四块 #444 直角底彻底消失；"灰 → 灰白"的擦除仍由卡面 .26s 淡出驱动。
