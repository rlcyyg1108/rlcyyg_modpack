## 本次改动（index/test.html，第 1 项需求）
需求：切换板块时刻度环高速旋转约 0.5s，减速慢一点。

实现：初速度 + 指数衰减（帧率无关），只动 `#decor` 这一层。
- 新增常量 `AUTO_SPEED=6 / KICK_V0=420 / KICK_TAU=0.40 / KICK_STOP=6`，状态加 `state.kickV`。
- 抽出 `renderDecor()`，`renderRotation()` 末尾改为调用它；animLoop 里每帧只重画 decor（顺带省掉每帧 5 次 querySelector）。
- animLoop 里 `if (mode !== 'rot')` 内做：常驻 6°/s + 冲量叠加，`kickV *= Math.exp(-dt/KICK_TAU)`。拖拽时冲量冻结。
- `select()` 的 `if (!silent)` 块内 `state.kickV = KICK_V0`（用 `=` 不用 `+=`，重复点击只重置不叠加），并用 `reduceMQ` 挡掉 prefers-reduced-motion。
- 实测：高速段 0.52s、1.70s 停下、冲量共约 169°，60fps 与 144fps 结果一致。

## 本次改动 6：移动端「上盘下屏」重构
方案：圆盘在上半屏（不滚）当常驻导航，下半屏 `#mStack` 独立滚动承载全部内容。

**关键设计决策：移动端样式全部挂在 `body.is-mobile` 上，不用媒体查询。**
原因：四角面板是 `position:fixed` 的 body 子元素，纯 CSS 无法让它们进入下方内容流，必须由 JS 搬运进 `#mStack`。一旦 CSS 用媒体查询、JS 用 `matchMedia`，两条判定可能分叉导致内容消失。现在由 JS 单点判定后加类，CSS 全部跟随，零分叉风险。

- **JS 重排**（`applyLayout()`，启动时调用一次 + `mqMobile` change 监听）：`toMobile()` 依次把 `.panel-right`、`.panel-left`、11 个 `.corner-panel` 搬进新建的 `#mStack`（右栏先放，使 links 态「链接」标题排在徽章前）；`toDesktop()` 按预先记录的 `_home`/`_next` 原样还原。
- **markup 修正**：`影像` 的 `.corner-panel.br[data-corner=interests]` 原本被错嵌在 `乐队` 面板内部，初始化时提到 body 层（插入 `.corner-panel.br[data-corner=projects]` 之前）。
- 断点串 `'(max-width: 768px), (max-height: 560px) and (orientation: landscape)'`，横屏矮视口额外走 flex-row（圆盘左 40vw / 内容右）。
- 高度改 `100dvh`（保留 `100vh` 兜底）；meta viewport 加 `viewport-fit=cover` + `env(safe-area-inset-*)` 内边距。
- 字号从原来的 11~12px 提到 15px 档；`.cols` 三列 8em 固定网格改 `repeat(auto-fit, minmax(96px,1fr))`；`.p-sub/.corner-sub` 解除 `nowrap`；徽章竖排改横排换行。
- 底部角面板的「正文在上、标题在下」用 `order: -2/-1` 把 `ac-name`/`ac-en` 提到卡片顶部。
- 删掉 `#mobileNotice`（"请用 PC 查看"）及其 JS toggle 行；鸣谢块的行内 `style="font-size:32px"` 换成 `.p-desc.lg`（行内样式移动端无法覆盖）。
- `#rimHit` stroke-width 22→34（约 18px 命中区）；`.s-name` 22→30px（盘变小后文字按比例缩到 11px）。
- 触屏 `:hover` 粘滞：`.sector:hover` 包进 `@media (hover:hover) and (pointer:fine)`，`syncTargets()` 加 `hoverMQ` 守卫。
- `select()` 里加 `if (mStack) mStack.scrollTop = 0`。

## 项目约定（重要，后续改版要遵守）
**排版类分两套：`p-*` 用于左右两栏 `.pane` 与 core 态角面板；`ac-*` 用于其余四角面板。写 CSS 时若只覆盖其中一套，会造成 core 态与其它板块观感不一致** —— 尤其是移动端那组「标题置顶 order」和字号规则，必须两套都写。
