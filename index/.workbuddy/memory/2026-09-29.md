## 本次改动 8：四角面板类名全站统一 + 修两个 bug

### 1. 类名统一（ac-* 全部退役）
四角面板原本混用三套：`p-*`（左栏「我」、core 的「关于」）、`ac-*`（其余 9 块）、以及用户手改的嵌套混合体。现在**只保留 `p-name / p-en / p-desc`**，`.ac-name/.ac-en/.ac-desc` 三条定义已删除。

关键：统一不能靠"简单改名"，因为两套类唯一的实质差异是 `.p-en{margin-bottom:16px}` vs `.ac-en{0}`，而下角面板是「正文→副标题→标题」倒序，副标题必须紧贴标题。**差异改用位置选择器表达**：
```css
.corner-panel.bl .p-en, .corner-panel.br .p-en { margin-bottom: 2px; }          /* 下角：紧贴标题 */
.corner-panel.br[data-corner='projects'] .p-en { margin-top: auto; margin-bottom: 2px; }  /* 撑满高度压到角上 */
```
已验证：标题/正文上下角计算值完全一致，副标题 上角16px / 下角2px（与原 ac-en 行为一致）。

「近况」DOM 展平为 `p-desc → p-en → p-name`（保留用户想要的右下角倒序，不再是嵌在 p-desc 里）。

### 2. Bug：隐藏面板里的链接「全局可点」
根因：`.corner-panel` 只有 `opacity:0`，元素仍在参与命中测试；而 `.corner-panel a { pointer-events: auto }` 无条件生效 → 隐藏面板的链接是隐形热区。贡献面板因同时设 `top`+`bottom` 撑满右侧高度，热区几乎全屏。
修复：`.corner-panel` 加 `visibility: hidden`（配 `transition: opacity .35s, visibility 0s linear .35s`，显示侧 `0s linear 0s`），链接规则收窄为 `.corner-panel.visible a`。额外加 `body.boot .corner-panel.visible a { pointer-events: none }` 堵住入场那 1.1s 延迟窗口。
副作用（正面）：visibility:hidden 顺带把隐藏链接移出 Tab 聚焦序列。

### 3. Bug：移动端切换没有上浮特效
根因：`.pane`（我）用 `animation: fadeIn`，`.corner-panel`（关于）用 `transition: opacity`。
**CSS 动画在 `display:none → block/flex` 时会播放，transition 不会** —— 移动端四角面板正是 display 切换，所以过渡被整个跳过。
修复：`.corner-panel.visible { animation: fadeIn .35s ease both }`，与 `.pane` 完全一致。

**踩坑**：boot 规则原本是 `animation: bootPanel .8s ... 1.1s both`。若保留，2.4s 摘掉 `body.boot` 时动画名由 bootPanel 变回 fadeIn → **动画重新播放一次（闪一下）**。所以 boot 期间只能覆写 `animation-delay/duration`，绝不能改动画名：
```css
body.boot .corner-panel.visible { animation-delay: 1.1s; animation-duration: .8s; }
```

## 本次改动 9：背景主动化 + 弧中点双向生长 + 入场打断修复 + 选中态/键盘可达

### 1. 背景：被动 → 主动（body::before 换成 #bgField）
- **伪元素不能用 JS 驱动 transform**，所以 `body::before` 换成真实 `<div id="bgField">`（`position:fixed; z-index:-1; pointer-events:none`），旋转由 animLoop 里的 `bg` 状态驱动，与刻度环冲量同一套 dt 模型。
- **中心对称**：色标严格关于 50% 对称（0%↔100%、26%↔74%、44%↔56%），渐变轴 `0deg`（等值线水平）。这样转起来是「一条线绕中心转」，而不是原来 115deg 斜渐变的「墙纸在转」。
  - `rotate(0)` = 亮带横着，`rotate(90)` = 竖着。
- **板块映射**：亮带是一条穿过圆心的线，必然同时指向一对相反扇区，所以两板块共用一档：`BG_ANGLE = {projects:0, links:0, interests:90, artists:90}`。core 态恢复被动自转（12°/s，沿用用户调过的 30s/圈）。
- **顺时针取档**：`to = want + Math.ceil((angle-want)/180)*180`，若 `to-angle<1` 则 `+180`（已在该档位也要转半圈，保证每次切换都有动作）。**bg.angle 只累加不取模**——取模那一帧会反向回跳。

### 2. 弧：从「顺时针单向」改成「从交点向左右同时生长」（核心技巧）
`pathLength=1`，设实线长度 L，用 dashoffset 把它挪到居中位置：
```
实线区间 = [-offset, -offset+L]  ≡  [.5-L/2, .5+L/2]
⇒ offset = L/2 - .5
```
所以隐藏态 `stroke-dasharray: 0 1; stroke-dashoffset: -.5`，显示态 `1 1 / 0`。两个属性等时长等曲线插值 ⇒ 任何中间帧都严格居中。
**时序**：生长 = 线 .5s(0s) → 弧 .55s(.45s)，共 1s；消散 = 弧 .55s(0s) → 线 .5s(.5s)，共 1s。即「隐藏态的 transition 描述消散、.show-* 态描述生长」。

### 3. 修 bug：入场没跑完就点板块 → 文字要等 1s 多才出现
根因：`body.boot .corner-panel.visible { animation-delay: 1s }`。新面板刚拿到 `.visible` 时动画重新播放，被 boot 的延迟套住。
修复：`endBoot()` —— 交互即摘 `boot`、清掉两个 boot 定时器、重算尺寸。**关键**：直接摘 boot 会让还卡在 delay 里的元素硬跳，所以同时加 `boot-skipped`，用一段 `.25s` 的 bootFade 把终态走完（`animation` 由 none 变成有名字会立即播放）；.3s 后移除该类。

### 4. 入场四块 delay 统一
原来 `.panel-left`(1s) / `.panel-right`(1.15s) / `.corner-panel.visible`(1.1s) 三档不同，左右四块明显错开半拍。统一到 1s / .8s。

### 5. 选中态三层反馈
原来 selected .26 vs hover .16 只差 0.1。改为：外弧 `.ring-line.sel`（stroke .9 / width 2.6 / 光晕，主）+ 标签 `.s-label.sel` 提亮 + 扇区填充 .26→.34。外弧索引 `SECTORS.findIndex(s=>s.id===id)`，core 时为 -1（无外弧）。

### 6. 键盘可达
扇区与 hub 加 `tabindex=0` / `role=button` / `aria-label`，Enter/空格触发 select。svg 的 `role="img"` 改 `role="group"`（否则 AT 会忽略内部的 button）。`:focus-visible` 用填充+光晕表达（SVG 的 outline 在部分浏览器画不出来）。

### 7. 顺手修的既有问题
`animLoop` 的 dt 只有上限钳制，首帧 `performance.now()` 基准晚于 t 时 dt 为负 → 刻度环和背景会先倒转一下。补 `Math.max(0, ...)`。

### 8. 按用户要求
- 删除 `.r-lines.badges img.white-icon`（定义了但无元素使用）
- `body` 字体补 `'Noto Sans SC'`（放 Arial 之后：拉丁仍走 Arial，中文落到 Noto Sans SC）
- 不改：徽章尺寸/风格、文字层级、背景 30s、Orbitron 的 `font-weight:100 900` 声明

## 本次改动 10：链接板块改两级收藏库（骨架已完成，等书签数据）

### 背景
链接板块原本是四个板块中最空的：0 块角面板（喜好4/记忆4/项目1），只有右栏三行字 + 左栏 8 个**自己的账号徽章**。标题 `LINKS` 承诺收藏、给的是账号入口，语义错位。用户有几十上百个分类收藏。

### 结构（已实现）
两级，共用同一批 `[data-link-slot]` 容器（4 个，对应四角 tl/tr/bl/br），只换内容不换节点：
- **目录层** `linkCat === null`：四角各一张 `.link-cat` 分类卡（p-name/p-en + `.link-peek` 预览 3 个站名 + 条数）
- **条目层**：四角分摊当前分类的条目，`per = ceil(items/4)`；**只有 slot0 带 p-name/p-en 标题**，其余三角纯列表（避免标题重复 4 次）
- 右栏 `p-desc#linkMeta` 显示计数（由 JS 从数组算，不手写）；`#linkBack` 按钮在条目层显示
- 切到别的板块 → `select()` 里重置 `linkCat = null`，下次点链接扇区回到目录层

**关键坑**：两个层级共用容器，`.visible` 不会被重置，所以 `fadeIn` 不会自动重播 → 必须手动 `replayLinksFade()`（清 animation → `void offsetWidth` → 还原，与 `.pane` 同套路）。

数据格式 `LINKS = [{cat, en, items:[{n, u, d}]}]`，全部走 DOM API 构建（不用 innerHTML，书签标题可能含 `&` `<`）。当前是 4 类 20 站的**占位数据**，等用户导出书签后整份替换。
